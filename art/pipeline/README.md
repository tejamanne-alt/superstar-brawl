# Concept-art pipeline (Blender + comic shader)

Everything in `art/concept/` is generated by code: procedural 3D in **Blender 5.2 (bpy)**, rendered with Cycles to
multilayer EXR passes, then painted into the comic look by `sb/comicfx.py`. No hand painting, no AI image generation.

```
pip install bpy==5.2.3 numpy pillow opencv-python-headless OpenEXR   # Python 3.13
VP=$(which python) ./run_all.sh                                       # ~12 min on 4 CPU cores
```

| Module | What it does |
|--------|--------------|
| `sb/geo.py` | spline lofts (limbs, torso, hair clumps, mustaches), deformed-sphere blobs, material registry |
| `sb/character.py` | rig and pose solver → lofted body with clothing seams, folds, hands, shoes, jackets, coats, dhotis |
| `sb/head.py` | caricature heads: BVH-projected eyes, brows, nose, mouth, ears, hair, beards, glasses, cap, bandage, mask |
| `sb/props.py` | towel, bicycle chain, lathi, flipping shades, watch, epaulettes, energy FX, varma strike lines |
| `sb/roster.py` | the 9 fighters: palette, face knobs, outfit, signature pose (+ alternate gameplay poses) |
| `sb/environment.py` | Stage 1 rooftop, procedural city, monument, kites, wires, billboard; Stage 2 promenade |
| `sb/scene.py` | Cycles setup, render passes, camera/sun, 3D→screen anchors |
| `sb/comicfx.py` | the comic shader (cel bands, halftone, hatching, ink, rim, spec, glow, misregistration, paper) |
| `sb/paint.py`, `sb/compose.py` | painted skies, haze, speed lines, bursts, comic text, HUD widgets |
| `render_*.py` | Blender scenes → `art/build/*.exr` |
| `compose_*.py` | EXR → finished boards in `art/concept/` |

Debug helpers: `debug_lineup.py` (all fighters, flat shading), `debug_heads.py` (face close-ups), `preview.py`.

To tweak a fighter, edit their entry in `sb/roster.py` (face knobs, palette, pose directions), then run
`render_card.py <id>` + `compose_cards.py <id>`.
